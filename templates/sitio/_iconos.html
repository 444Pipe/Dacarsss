{% load static %}{% comment %} Los iconos del sitio, en un solo lugar para que cambiarlos no obligue a tocar cada pagina. Cuadrados y con fondo negro propio: antes eran el logo con fondo transparente y cada lugar que los mostraba les ponia el fondo que queria. Se generan con tools/generar-iconos.py. Todos van por {% static %}, que les pone la huella del contenido en el nombre (favicon..ico). No es detalle: el navegador guarda el icono por direccion, y con una fija como /favicon.ico se queda con el viejo aunque el archivo cambie. Con la huella, un icono nuevo es una direccion nueva. {% endcomment %}
